# Examples

`tracing.py` is a marimo notebook — a cold absorbing gas heated by a hot wall,
on either a 3D cylinder or a 2D plane. It documents itself; these are the two
things it cannot tell you from the inside.

```
uv run python examples/meshes/generate.py    # meshes are generated, not committed
uv run marimo edit examples/tracing.py
```
